🛠️ Installation
(Client-side only – No server setup needed!)

Clone the repo:

bash
git clone https://github.com/your-username/deadlock-detector.git
Navigate to project:

bash
cd deadlock-detector
Open in browser:

bash
open index.html  # macOS
start index.html # Windows
xxdg-open index.html # Linux
🚀 Usage
💬 Chat Interface
Type your question ➡️ AI provides detailed answers

Use quick buttons for common topics

🔄 Simulation Tool
➕ Add processes (P) & resources (R)

📋 Define allocation/request matrices

⚠️ Click "Detect Deadlock"

📊 View results: Safe Sequence or Deadlocked Processes

📖 Educational Guides
Navigate to Guide or Algorithms tabs

Browse categorized deadlock concepts

🔑 API Key Setup
(Required for AI responses)

Get a Gemini API key from Google AI Studio

Replace placeholder in script.js:

javascript
const API_URL = "https://generativelanguage.googleapis.com/...YOUR_API_KEY";
(⚠️ For production, use a proxy server instead of exposing the key!)
